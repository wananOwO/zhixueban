# 演示视频分镜脚本（5–8 分钟，1080p，普通话）

演示素材使用公开教材（Python 官方中文教程、OI Wiki），不使用版权不明的书。

| 时间 | 画面 | 解说要点 |
|---|---|---|
| 0:00–0:40 | 首页（最近课程的下一步、掌握条、路线图） | 痛点：教材几百页，比赛只考其中一部分；AI 讲得对不对也没法核对。智学伴按目标重排教材，每句讲解都写明出自原书第几段 |
| 0:40–1:20 | 教材库：拖入 EPUB 与 MOBI | 七种格式内置解析，MOBI 不需要 calibre；打开教材详情，原文按段号排列 |
| 1:20–2:10 | 课程草稿：写目标「蓝桥杯 Python 组」，选章节，点生成 | 目标、资料、教学要求、考核方式四个分区，自动保存 |
| 2:10–3:10 | 生成过程页 | 执行记录实时出现：读取原文、搜索公开资料、提交知识点；某次提交没通过校验，Agent 修改后通过。书带上灰色是读过的段落，朱红细线是采用的出处 |
| 3:10–3:50 | 方案审核：先修路线图 | 故意排除一个必需先修，出现问题提示且不能确认；恢复后勾选核对，确认成为正式课程 |
| 3:50–4:50 | 学习页：课件 | 宋体正文、右侧朱批旁注；被引用的那一句下面画线；点旁注打开原书并定位到第 N 段。选中一段文字「就这段提问」，助教流式回答并标出处 |
| 4:50–5:50 | 学习页：题组 | 选择题答对出现朱批勾；编程题提交到 Judge0 判分；逐级打开提示，第 4 级完整解析需要确认，且之后的作答不计入掌握 |
| 5:50–6:30 | 课程主页 | 路线图节点按证据着色；掌握标准说明；切换理论 / 练习 / 刷题模式，记录保留；笔记导出 Markdown、写入 Obsidian |
| 6:30–7:10 | 线上站与 AI 协同开发过程 | 线上站访问码登录，Key 只存在浏览器；展示开发中如何用 Agent 按计划逐个任务实现、先写测试再写代码、用截图检查修设计问题 |
| 7:10–7:30 | 结尾 | 技术栈一页、开源声明、联系方式 |
