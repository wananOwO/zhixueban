# 单一学习工作台实施计划

> 使用 executing-plans 按顺序实施。用户已明确授权删除冗余，不保留旧网址跳转或历史兼容；不提交 Git、不删除开发数据库。

**目标：** 单一首页、统一导航和教材/建课流程；教学方案单选；可靠保存与生成；支持模型列表查询选择。

**架构：** 保留增强 API 的领域语义及持久任务。唯一首页 `/`，业务详情暂保留现有 `/verified-learning/...` 路径但不再暴露“增强/旧版”产品区分。删除旧页面、旧 API、专用 agent/RAG/统计以及旧记录兼容端点；数据库建表版本不做破坏性重置。

**技术：** Next.js 16.4.2、React 19、TypeScript、Vitest、现有 Playwright/Chromium。

## 任务

1. [x] 单一导航与冗余删除：Shell 统一于根 layout；首页显示继续学习/新建/教材与最近任务，而非第二份导航目录。删除旧页面/API及无引用专用实现；移除 legacy UI/端点/类型。导航测试校验五个主入口、无重复首页与旧链接。
2. [x] 草稿：教学方案代替模板+学科两个选择，关联 subjectType/templateId，计算机默认 Python，额外提示不复制模板。教材选中即加入，章节显式选择+全选；逐项列出阻塞原因。保存队列串行、失败停住并保留key重试；生成等待所有保存成功。waiting_user刷新审核，失败可重试/返回编辑。浏览器模拟延迟/失败/生成结果，不能调用真实模型收费。
3. [x] 模型列表：POST settings/models，显式按当前表单或已存配置查询；OpenAI兼容与Anthropic，超时、非JSON、鉴权失败和不支持列表可恢复；不持久化临时输入，不泄露key，不跟随重定向。切换地址/协议使列表失效；成功选择，失败手填。服务端mock测试和浏览器mock验证。
4. [x] 审查与验收：定向与全量测试、tsc/build/diff；真实浏览器导航、教材到草稿、自动保存、审核确认、390px窄屏；更新交接结果，准确说明未实测真实供应商。

## 风险与验收重点

- 删除存量未提交旧API属于用户最新明确清理范围；无关增强后端保留。
- 无来源不能生成，但必须给出具体引导；不得绕过后端来源/先修校验。
- 保存网络失败不得循环请求；409不覆盖本地。
- 模型查询不能把已存密钥发到未经明确填写新密钥的新地址。
- 取消兼容不等于自动删除数据库文件；迁移历史及底层仍需使用的表结构暂保留。
