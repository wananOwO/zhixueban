# 示例课程

线上站的每个新空间会自动复制一门预置示例课程，评委不填模型 Key 也能读课件、答题、看生成过程回放。

## 机制

- 导出：`pnpm vl:sample-export --db <库> --scope <空间ID> --course <课程ID> --out <文件>`，只读打开数据库。
- 种入：线上模式下，浏览器第一次用访问码登录、新建空间时，读取环境变量 `VL_SAMPLE_PATH` 指向的文件并写入该空间。未配置或文件不存在时跳过，线上站照常可用。
- 实现：`src/lib/verified-learning/sample-course.ts`；测试：`tests/verified-learning/sample-course.test.ts`、`sample-seed-http.test.ts`。

## 导出包含什么

| 内容 | 处理 |
|---|---|
| 课程活跃版本、方案审核记录、确认它的草稿 | 原样 |
| 课程用到的资料与来源快照 | 原样；不带上传文件，`file_relpath`、`file_hash` 置空（不占空间的上传额度） |
| 学习会话 | 重置为未开始：第一份已生成内容（通常是课件）作为当前活动 |
| 已生成的课件与题组 | 第一份为 `ready`，其余为 `prepared`（已生成、未开始；开始时不新建生成任务，不需要 Key） |
| 方案、课件、题组的生成任务与事件 | 只保留终态与结果；`input_json` 置为 `{}` |
| Agent 会话记录 | 只保留轨迹需要的工具调用：工具名、读取区间、搜索词、引用段号、题号、错误类别关键词；不含系统提示、模型文字、引文、工具反馈原文、中间产物、模型名 |

不导出：作答、提示记录、笔记、幂等请求记录、学习事件、其他草稿。

## 教材要求

示例课程的教材必须可公开（规格 8.4）：用 Python 官方中文教程（PSF 许可）和 OI Wiki（CC BY-SA 4.0）的页面，页脚注明来源与许可。当前开发库里的《Python编程：从入门到实践》不能用于线上站和演示视频。

## 生成真实示例课程（需要用户授权模型费用）

1. 在一个一次性本地库里上传公开教材，按正常流程生成方案、确认，学完第一个课件并生成第一组练习（不作答）。
2. 用 `pnpm vl:sample-export` 导出到服务器数据目录，例如 `/srv/zhixueban/data/sample/course.json`。
3. 在服务的环境变量里设置 `VL_SAMPLE_PATH` 指向该文件并重启服务。
